# C# 快速上手学习平台 (PM 转型版)

这是一个专门为你设计的 C# 学习平台，界面参考 Microsoft Learn 风格，内容针对产品经理转开发的需求进行了深度定制。

## 目录结构
- `Documents/CSharpLearning/` — 你的主练习目录
- `csharp-course-web/` — 交互式学习平台 (Vue + Flask + JDoodle API)

## 如何启动 (快速启动)
1. **打开终端**，进入项目目录：
   ```bash
   cd ~/Documents/CSharpLearning/csharp-course-web
   ```
2. **启动平台服务器**：
   ```bash
   python3 proxy.py
   ```
3. **在浏览器中访问**：
   [http://localhost:5001](http://localhost:5001)

## 10 天深度进阶大纲 (每天 2-4 小时)
本课程结合了 Microsoft Learn 的核心知识点与产品开发实战逻辑。

### 第一阶段：语言基础 (Day 1-4)
- **Day 1**: 语法结构与输入输出（Main 方法、控制台、字符串转义）
- **Day 2**: 变量深度探索（值类型 vs 引用类型、类型转换、字符串插值）
- **Day 3**: 逻辑决策系统（If, Else, Switch, 三元表达式与复杂条件组合）
- **Day 4**: 集合与数据批处理（数组、ForEach 循环、List<T> 动态集合基础）

### 第二阶段：面向对象与业务逻辑 (Day 5-7)
- **Day 5**: 方法与逻辑抽象（参数传递、返回值、重载方法）
- **Day 6**: 类与对象：建模你的业务（类定义、属性 Get/Set、构造函数）
- **Day 7**: 面向对象进阶（继承、接口 Interface —— 理解微软项目的核心解耦方式）

### 第三阶段：高级特性与工程实战 (Day 8-10)
- **Day 8**: LINQ 数据查询神器（Where, Select, OrderBy —— 像操作 Excel 一样操作对象）
- **Day 9**: 异常处理与文件操作（Try-Catch 实战、JSON 文件读写）
- **Day 10**: 异步编程 (Async/Await) 与 API 调用（理解现代 Web 应用的响应机制）
